Abstract

This work introduces CASPA, a framework for improving adaptation in vision–language models. Instead of assigning independent prompts to each category, CASPA learns a shared set of semantic concept anchors that exist in both visual and textual embedding spaces. Class representations are constructed as weighted combinations of these anchors, encouraging parameter sharing across categories and improving robustness in few-shot learning settings. The proposed method supports efficient generalization to unseen classes and cross-dataset transfer without retraining the backbone model. Experiments across multiple datasets demonstrate strong improvements in base-to-novel generalization and few-shot recognition.
