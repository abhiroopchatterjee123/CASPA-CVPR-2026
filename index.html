Abstract

Our work "CASPA: Graph-Structured Concept Anchors for Modality-Agnostic Adaptation in Vision–Language Models," presents a structurally constrained alternative to class-conditional prompt parameterization. Rather than allocating independent prompt embeddings per category, CASPA decomposes class prototypes into soft combinations over a shared set of learnable semantic anchors instantiated in both textual and visual latent spaces. These anchors form a low-rank, graph-structured basis that captures recurrent semantic directions across categories, and enables prototype reconstruction via anchor-weighted aggregation with residual refinement. This compositional parameterization induces parameter sharing, reduces overfitting in low-shot regimes, and robust generalization to novel classes via confidence-adaptive zero-shot prototype scaling, all while keeping the backbone frozen.
